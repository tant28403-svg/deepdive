# Security Policy

## Reporting a vulnerability

If you discover a security vulnerability in deepdive, please report it responsibly:

- Email: (add contact) or open a private security advisory on GitHub.
- Do not open a public issue for security vulnerabilities.

We aim to acknowledge reports within 72 hours and provide a fix within 30 days.

## Scope

- Vulnerabilities in the deepdive tool itself (e.g., parser exploits, path traversal in archive extraction, sandbox escapes).
- False negatives that allow malicious code to pass undetected (treated as high priority).

## Out of scope

- Malware samples themselves (deepdive is a scanner, not a malware repository).
- Vulnerabilities in scanned third-party code.
